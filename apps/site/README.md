# Site Arqevon Code

Landing page pública da Arqevon Code e página de download do Arqevon Finance.

Produção: https://arqevon-site.vercel.app

## Desenvolvimento

Requer Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

## Validação

```bash
npm test
npm run lint
```

Os instaladores atualmente publicados ficam em `public/downloads`. Substitua um arquivo somente depois de validar o aplicativo na plataforma correspondente e atualizar o registro em `../../docs/PRODUCTION_BASELINE.md`.
